# bio-jose

Сайт Jose Mourinho.

## 📱 Что это?

Минималистичная страница-биография с ссылками на:
- **Telegram-канал** 
- **TikTok профиль**

## 🎨 Дизайн

- Тёмная тема с градиентом
- Мобильное меню
- Плавные анимации при наведении
- Отзывчивая верстка

## 🚀 Как использовать?

1. Откройте файл `index.html` в браузере
2. Или разверните на GitHub Pages для публичного доступа

## ⚙️ Как редактировать?

Откройте файл `index.html` и измените:
- **Имя**: найдите `<h1 class="name">Jose Mourinho</h1>`
- **Описание**: найдите `<p class="bio-text">Привет! Подписывайся...</p>`
- **Аватар**: замените `<div class="avatar-placeholder">JM</div>` на `<img src="your-photo.jpg">`
- **Ссылки**: обновите `href` в кнопках Telegram и TikTok

## 📄 Лицензия

Свободный код — используйте как хотите!
